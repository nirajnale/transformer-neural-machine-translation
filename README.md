# 🌍 Transformer-based Neural Machine Translation

A deep learning NLP project implementing an **Encoder-Decoder Transformer Architecture** for sequence-to-sequence neural machine translation using **TensorFlow/Keras**.

This project demonstrates the complete Transformer translation workflow including:

✅ Tokenization & Padding  
✅ Word + Positional Embeddings  
✅ Encoder-Decoder Architecture  
✅ Masked Multi-Head Attention  
✅ Feed Forward Networks  
✅ Sequence-to-Sequence Learning  
✅ Text Translation Prediction  

---

# 🧠 Transformer Architecture

The project uses a complete **Encoder-Decoder Transformer** architecture consisting of:

## Encoder
- Embedding Layer
- Positional Encoding
- Multi-Head Self Attention
- Feed Forward Network
- Add & Layer Normalization

## Decoder
- Masked Multi-Head Attention
- Encoder-Decoder Attention
- Feed Forward Network
- Dense + Softmax Output Layer
